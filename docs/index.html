feedkit

Agentic-first RSS/Atom feed reader and aggregator

Go Single Binary Zero Deps MCP Plain Text API

What is feedkit?

feedkit is an RSS/Atom feed reader designed for AI agents, not humans. No UI, no SDK. The API is the product. Subscribe to feeds, fetch entries, search across all subscriptions — all through plain HTTP.

Quick Start

# Build
make build

# Run
./feedkit

# Subscribe to a feed
curl -X POST http://localhost:8790/feeds \
  -H "Authorization: Bearer TOKEN" \
  -d "url=https://example.com/feed.xml"

# List entries
curl http://localhost:8790/entries \
  -H "Authorization: Bearer TOKEN"

Key Features

Agent-First

The AI agent IS the interface. No UI, no SDK. Plain text responses that are token-cheap and grepable.

RSS + Atom

Full support for RSS 2.0 and Atom 1.0 feeds. Automatic parsing and normalization.

Search

Search across all entries by title or summary. Find what matters across all your subscriptions.

Read/Star

Mark entries as read or starred. Track what you've seen and what matters.

MCP Support

Speaks Model Context Protocol at /mcp for chat client integrations.

Single Binary

Go + JSON file storage. Zero external dependencies. Deploys as one file.

API Overview

Auth

POST /auth/request  email=user@example.com
POST /auth/verify   email=user@example.com code=123456
→ token=xxx workspace=ws_xxx

Feeds

POST   /feeds              url=https://example.com/feed.xml
GET    /feeds
GET    /feeds/{handle}
POST   /feeds/{handle}/refresh
DELETE /feeds/{handle}

Entries

GET  /entries?feed=feed_xxx&limit=20
GET  /entries?q=keyword
GET  /entries/{handle}
POST /entries/{handle}/read
POST /entries/{handle}/star

Response Format

Plain text by default — one labeled, grepable line per record:

handle=entry_xxx title=First Post link=https://example.com/post1 published=2026-08-18T10:00:00Z read=no starred=no

JSON on demand via Accept: application/json or ?format=json
